## Инженерные ограничения

- Roblox Luau, безопасное client/server разделение, никакие клиентские `damage` не признаются сервером как истина. Текущие Roblox API уточняй на официальном Creator Hub.
- Не создавать сотни полноценных Humanoid с дорогой физикой/AI. Использовать лёгкие NPC и настраиваемый spawn cap; риски качества на мобильных задокументировать.
- Реальные звуки попаданий, muzzle flash, реакция целей и death — обязательный геймплейный результат P1A. Placeholder art допустим там, где он не ломает читаемость, но UI и механики не должны быть технической заглушкой.
- Реальные файлы и запуски важнее длинных рассуждений. Не заявляй «игра готова», если только написал генератор кода или создал структуру без проверки в Studio.
- Не выполнять `Publish`, public release, `Marketplace` purchases, developer products, платные asset actions, удаление пользовательского проекта, миграцию с риском потери данных без отдельного согласия.
- Не внедрять валюты, DataStore профиля, VIP, battle pass, full coop, второго биома, десятков пушек, блуждающих концептов и auto-shoot вместо ручного управления.
- Не подменять Roblox импорт/текстуры невозможным или недоступным API; если asset pipeline ограничен, используй законные минимальные средства и фиксируй зависимость для следующего шага.
