# SWARMFALL 3.0

Roblox top-down horde shooter (интерфейс на русском). Держись 8 минут против роя, собирай улучшения, вырви ядро
эволюции у элиты, превращай оружие в оружие массового поражения — и убей босса. Соло или отряд до 4 игроков.

> Исходный дизайн-пакет (docs/, agent/, assets/) не тронут. Старый прототип P1A лежит в `legacy/P1A/`.

## Запуск

```bash
rojo build -o build/SWARMFALL.rbxlx
```

Открыть `build/SWARMFALL.rbxlx` в Roblox Studio → Play (или `rojo serve` + плагин Rojo для живой синхронизации).
Арена, свет и remotes создаются сервером при старте — в Edit-режиме место пустое, это нормально.

**Сохранения:** профиль хранится в DataStore. В Studio без «Enable Studio Access to API Services» профиль работает
в офлайн-режиме (звёздочка возле скрапа) — ничего не пишется и ничего не стирается.

**Studio-команды для тестов** (только в Studio): из command bar клиента
`game.ReplicatedStorage.Remotes.Input:FireServer("devGrant")` — 5000 скрапа и открыть карты/угрозы;
`"devLevel"` — уровень; `"devGod"` — бессмертие; `"devSkip", 419` — перемотать к боссу.

Тесты (без Studio):

```bash
lune run tests/compile
lune run tests/sim_run all
lune run tests/sim_run batch 1 6 MAP_HIVE_DEPTHS 1
```

Превью без Studio: `lune run tools/export_icons > icons.json && python tools/render_icons.py icons.json icons.png`,
`lune run tools/export_models > models.json && python tools/render_models.py models.json weapons.png weapons`.

## Контент

| | |
|---|---|
| **Карты** | Реакторный двор (босс: Матка разлома) · Глубины улья (босс: Пожиратель, новые враги Взрывуны) |
| **Угроза 1–5** | на каждой карте; победа открывает следующую. +25% HP, +12% урона врагов за уровень, награда ×1.35 |
| **Оружие** | Дуговая винтовка · Дробовик «Вулкан» · Лучемёт «Разлом» · Рельсотрон (покупается за скрап) |
| **Эволюции** | Громовержец · Адская мельница · Копьё пустоты · Звездолом (2 ключевых улучшения + ядро элиты) |
| **Улучшения** | 12 × 3 ранга, 6 слотов, синергии «Двойная дуга» и «Погребальный костёр» |
| **Враги** | Бегун, Прыгун, Плевун, Броненосец (бронированный фронт), Взрывун (цепные взрывы задевают и рой), Элита, Гнёзда |
| **Боссы** | Матка: удар конусом, кислотные дорожки, таран. Пожиратель: закапывается и вырывается под игроком, кольцо кислоты, призыв взрывунов |
| **Мастерская** | 8 перков за скрап: Живучесть, Магнит, Переброс, Изгнание, Форсаж, Реактор, Прозрение (4 карты), Утиль |

Скрап начисляется за убийства, уровни, итог и улей; умножается угрозой и «Утилем». Выдача идемпотентна по runId.

## Управление

| | ПК | Тач | Геймпад |
|---|---|---|---|
| Движение | WASD | левый стик | левый стик |
| Прицел / огонь | мышь / ЛКМ | правая площадка | правый стик / R2 |
| Рывок | Пробел / Shift | кнопка | B / L2 |
| Перегрузка | Q | кнопка | Y |
| Эволюция | F | кнопка | X |
| Улучшение | 1 2 3 4 / клик | тап | крестовина + A |
| Вид камеры | V / кнопка справа вверху | кнопка | крестовина ↑ / R3 |
| Пауза (соло) | P / меню Esc | меню Roblox | Start |

**Виды камеры:** сверху (по умолчанию) → от третьего лица → от первого лица → сверху. В видах от 3-го/1-го лица
прицел идёт за камерой (мышь захвачена, на геймпаде/телефоне — поворот стиком/площадкой). Переход — плавный
перелёт: смешиваются параметры камеры (дистанция, наклон, высота, плечо, FOV, поворот) по кривой ease-in-out,
поэтому камера опускается за спину по дуге, «влетает» в голову и взмывает обратно, а не прыгает.

## Бой: анимация и ощущение оружия

- **Персонаж** анимируется процедурно (`Rig`): стандартный Animate отключён. Оружие — часть тела (Motor6D на корне),
  обе руки решаются IK (двухзвенный решатель) на рукоять и цевьё; ноги — IK на «ступни», которые шагают с длиной и
  частотой шага по реальной скорости в любую сторону (стрейф, пятясь), с подъёмом стопы и покачиванием таза.
  Стойка боком к цели, наклон в движение, «низкая готовность» вне стрельбы, инерция оружия при повороте,
  отдача/вздрагивание/отклик корпуса — пружины. Перезарядки свои у каждого оружия (магазин, патроны по одному +
  помпа, сброс перегрева, открытие затвора), рывок и гибель — отдельные позы. Работает и для R15 (Motor6D и новых
  физических AnimationConstraint-суставов), и для R6.
- **Оружие = данные** (`WeaponFeel`): хват, отдача, механизм (помпа, откат ствола, кристалл), вспышка, снаряд,
  попадание, гильза, камера, звук. `Shots` применяет профиль одинаково для своих выстрелов и выстрелов отряда.
  - Винтовка: короткие яркие болты летят к цели, искры, светящиеся гильзы-ячейки; эволюция — молнии.
  - Дробовик: огненная вспышка и дым, веер дробин, сильный толчок, помпа рукой + вылетающая гильза.
  - Лучемёт: живой луч с двойной спиралью, вибрация в руках, искры в точке касания, сброс перегрева.
  - Рельсотрон: свечение заряда между выстрелами, белое ядро + спираль + кольца + дымный след, откат ствола,
    пробивание с выходными брызгами через каждую цель.
- **Камера**: отдача-подброс (в видах от 3-го/1-го лица), толчок против выстрела сверху, FOV-удар, тряска;
  прицел «раскрывается» на выстрел.
- **Враги** живые: походка по реальной скорости с подъёмом лап, крен в поворотах, дыхание и моргание, замах с
  отклонением назад и дрожью, выпад, отлёт и вздрагивание от каждого попадания в сторону выстрела (сервер шлёт
  источник урона), белая вспышка с затуханием, пыль от шагов тяжёлых, вылет из-под земли, разлёт по
  направлению убившего выстрела.

## Архитектура

```
src/shared/     Defs (контент, баланс, перки, награды) · Maps (геометрия и сценарий карт) · Codec (сеть)
src/server/     Main.server (лобби/забег/результаты, валидация, движение, хост) · Profile (DataStore) · Arena (2 темы)
src/server/Sim/ World (забег, директор, прогресс, реролл/изгнание) · Combat · AI (вкл. Взрывуна и Пожирателя) · Nav · Rng
src/client/     Main.client · Hud · Menus · Icons (векторные иконки) · Models (3D-оружие) · Creatures (чертежи врагов)
                Rig (процедурная анимация, IK) · WeaponFeel (профили оружия) · Shots (подача выстрела) · Spring
                Preview (вьюпорты) · EnemyView · Fx · Gear · Controls · CameraRig · Audio · Theme · Settings
tests/          compile · sim_run (бот проходит забеги целиком) · harness
tools/          export_icons/render_icons · export_models/render_models (офлайн-превью)
                render_dump / render_scene (рендер поз и эффектов, снятых из Play, когда вьюпорт Studio не рисует)
```

- Сервер решает всё: клиент шлёт только намерения, каждый remote проверяется по типам и лимиту частоты.
- Симуляция на чистом Luau → весь забег гоняется ботом в Lune, детерминирован по seed.
- Враги — данные, не Humanoid; репликация 11 байт/враг в `buffer`, ~6–9 КБ/с; на клиенте один `BulkMoveTo` за кадр.
- Иконки собраны из GUI-примитивов, модели — из деталей: никаких загрузок ассетов не требуется.
- Шрифты: Zekton / Oswald / Montserrat / RobotoMono — все с кириллицей.

## Звук

Используются только встроенные звуки движка (с изменённой высотой). Замени id в `src/client/Audio.luau` на
лицензированные `rbxassetid://` для полноценного звучания.
