# Ксенит: расколотая руда (DD-096)

Одобренный владельцем концепт: плотный асимметричный малиновый минерал, тёмные грани и светлая диагональная жила. Прозрачная иконка, отдельный осколок для банки и компактный запас руды на ящике используют этот мотив.

## Ресурсы

- `icon-source.png` — выделенная из концепта иконка с альфа-каналом, built-in imagegen, без фона; запрос сохранён в `icon-prompt.txt`.
- `icon.png` — готовая RGBA-иконка 256 × 256 с безопасными полями; `icon-sizes.png` — просмотр в 128, 64, 32, 24, 20, 16 и 14 px. Генератор подготовки: `tools/icons/xenite.js`, зависимость `sharp`.
- `xenite.blend`, `build_xenite.py`, `shard.fbx`, `cluster.fbx` — исходник и воспроизводимая фоновая сборка Blender.
- `palette.png` — общий атлас цветов 88 × 8, крупные грани без тяжёлых текстур. На модель — два MeshPart: непрозрачное тело и узкая Neon-жила, один PointLight без теней.
- `geometry.json`, `geometry-report.json` — точные треугольники Blender и бюджет: осколок **140**, скопление с камнями **520**.
- `asset-manifest.json` — реально загруженные в аккаунт владельца изображения и меши. Иконка: `113891813640404`.
- `assets/xenite/Shard.rbxm`, `Cluster.rbxm` — нативные игровые шаблоны, подключены в основном и тестовом Rojo-проекте. Сохранены импортные InitialSize и Content-ссылки. В игре только клонирование, ScaleTo и PivotTo; EditableMesh не используется.

## Воспроизведение

1. `blender --background --factory-startup --python production/xenite/build_xenite.py`
2. `node tools/icons/xenite.js [путь к sharp]`
3. Новую геометрию импортировать штатным Studio 3D Importer, creator Me. Текущие FBX уже загружены; повторная загрузка для обычной сборки не нужна.
4. В шаблонах масштаб импорта уменьшен в 100 раз. Blender `(X,Y,Z)` соответствует игровому `(X,Z,-Y)`; импортированные меши развёрнуты на 180° вокруг Y. Pivot тела стоит в точке контакта всей модели с поверхностью. Body — SmoothPlastic, белый множитель цвета, штатный TextureContent; Vein — Neon, розовый, без текстуры. Свет 0.35; в банке 0.2.
5. Для повторного извлечения после изменений сохранить локальное место с `ReplicatedStorage.XeniteAssets` в `build/xenite/import-workspace.rbxlx`, затем `lune run tools/package_xenite`. Проверка: `lune run tests/xenite`.
