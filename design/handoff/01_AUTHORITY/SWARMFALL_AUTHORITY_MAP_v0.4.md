# SWARMFALL — AUTHORITY MAP v0.4

**Единственная действующая карта приоритетов для этого комплекта.**

1. Прямые последние инструкции владельца и записи утверждений `SWARMFALL_D00_APPROVAL_RECORD_v0.2`, `v0.3`, **`v0.4`**.
2. `SWARMFALL_MASTER_GDD_v1.0.md`: игровая концепция и границы контента, **за исключением устаревшего предложения сначала дорабатывать прототип**.
3. `SWARMFALL_D01_COMBAT_GAMEPLAY_SPEC_v0.3.md`: утверждённые правила одиночного боя.
4. `SWARMFALL_D02_OPERATIONS_SPEC_v0.3.md`: утверждённые правила сюжетных операций O01–O06, C-A01, T1–T5.
5. `SWARMFALL_D03_PROGRESSION_ECONOMY_SPEC_v0.3.md`: утверждённая модель прогрессии, экономики, оружейных модулей, форм и исследований.
6. Файлы в `03_GAME_DATA/` — структуры и отправные числовые кандидаты; конкретные значения не являются подтверждённым балансом.
7. `05_SUPPORTING_DESIGN/` — исторически важные профильные источники. Если расходятся с пп. 1–5, побеждает нормативный документ.
8. `06_REFERENCE_PROTOTYPE/src.7z` — НЕ авторитет игрового дизайна. Разрешён re-use/adapt/rewrite без требования сохранить прежнюю структуру кода.

**Статусы:** APPROVED DESIGN = игровое правило принято, не тестировано; TUNABLE = число-кандидат, можно менять с замерами; HISTORICAL = читать только как исходный контекст; OPEN_NONBLOCKING = не мешает первому Solo Gate A, но не может молча заменить утверждённое правило.

**Кооператив:** `DEC-01` утверждён ТОЛЬКО для соло; `DEC-02…07` и кооперативные аспекты DEC-01 остаются OPEN. Это не разрешение агенту реализовывать кооператив по догадке.

**Главное правило для Claude/Codex:** отсутствие числового порога ≠ разрешение добавить новую валюту, слот, вид врага, обязательную миссию, paid revival или изменить исход боя. Допустимы обратимые настройки и локальные технические решения с подтверждением тестами.
