# SWARMFALL — D00 / ЗАПИСЬ ЯВНОГО УТВЕРЖДЕНИЯ v0.2

**Дата:** 22.10.2026  
**Основание:** Явное сообщение владельца от 22.10.2026: «Утверждаю все шесть рекомендуемых решений из SWARMFALL_D01_DECISION_PACKAGE_v0.3.md: DEC-01 только для соло, DEC-08 и D01-R01–R04. Зафиксируй решения в D00 v0.2, выпусти D01 v0.3 APPROVED DESIGN, обнови полный рабочий пакет. Кооператив пока не прорабатываем.»  
**Объём:** только шесть правил для **одиночной боевой системы** и режим изменения балансных данных агентом. Никакого разрешения на запуск разработки и никаких изменений исходников.

| Идентификатор | Решение | Статус | Граница |
|---|---|---|---|
| `DEC-01 / SOLO` | При `HP ≤ 0` в соло-попытке — один `LOSS`, без автоматического/платного возрождения; подтверждённый прогресс сохраняется | `APPROVED_SOLO` | Кооперативные нокдаун, revive и командное поражение — **OPEN в D04** |
| `DEC-08` | Агент меняет только маркированные `TUNABLE`: внутри утверждённых границ с журналом; без границ допустимы только `PROVISIONAL`-кандидаты для тестирования | `APPROVED_POLICY` | Утверждённых числовых пределов **не добавлено** |
| `D01-R01` | В одном авторитетном шаге гибель героя/обязательного объекта имеет приоритет над `WIN`; валидные KillEvent и уникальные компоненты не теряются | `APPROVED_DESIGN` | Нет сюжетной победы/открытия следующей операции при `LOSS` |
| `D01-R02` | Целевые группы нападения на реактор; физически достижимые и предупреждённые атаки, возможность перехвата | `APPROVED_DESIGN` | Конкретные HP/частоты/тайминги — `TUNABLE` |
| `D01-R03` | Top-down/TPS/FPS и ввод с разных устройств используют единый боевой resolver и правила урона | `APPROVED_DESIGN` | Коэффициенты/UX помощи Touch не утверждены |
| `D01-R04` | Сценарный первый O01, ограниченная вариативность повторов и бюджет угроз без скрытого накопления NPC | `APPROVED_DESIGN` | Количественные лимиты и конкретный набор encounter-вариантов требуют D02/тестирования |

## Явно НЕ утверждено

- Все решения `DEC-02…DEC-07` (отряды, допуск, компоненты, экономика коопа, сбои, карточки, смена лидера) остаются `OPEN`.
- Правила смерти/поднятия союзников из кооперативной части `DEC-01` остаются `OPEN`. Утверждённая соло-смерть не переносится на co-op по умолчанию.
- Числа (`HP`, `DPS`, `SpawnAttemptRate`, пороги и т. д.) и границы `approved_min/max` не утверждены; все тесты ещё `NOT_RUN`.
- Не утверждены конкретные атаки будущих боссов, содержание D02–D07, Roblox-архитектура и право на реализацию.

**Изменяемые нормативные файлы:** `SWARMFALL_AUTHORITY_MAP_v0.2.md`, `SWARMFALL_DECISION_LOG_v0.2.md/.csv`, `SWARMFALL_RULE_REGISTRY_v0.2.csv`, `SWARMFALL_D01_COMBAT_GAMEPLAY_SPEC_v0.3.md`, `SWARMFALL_D01_ACCEPTANCE_MATRIX_v0.3.csv`. Оригинальные v0.1 и v0.2 не переписываются.
