# SWARMFALL — полный автономный handoff для Claude Code

**Актуальное разрешение:** полная самостоятельная разработка, не Solo Gate A. Документы утверждённого игрового дизайна задают направление, но не требуют отдельного согласования каждого технического/балансного/непрописанного решения.

**Начать:** `START_HERE.md` → `CLAUDE.md` → `04_AGENT_HANDOFF/FULL_AUTONOMY_MISSION.md`.

## Материалы

- `01_AUTHORITY/`: утверждённые D00 и журнал правил, включая D01/D02/D03.
- `02_GAME_SPECS/`: MASTER GDD, D01 Combat, D02 Operations, D03 Progression & Economy.
- `03_GAME_DATA/`: начальные таблицы, кандидатный баланс, acceptance tests. Тесты в файлах — **НЕ подтверждение** их выполнения.
- `05_SUPPORTING_DESIGN/`: детали концепции, карты, HUB, UI, roster.
- `06_REFERENCE_PROTOTYPE/src.7z`: старый прототип как источник возможного повторного использования, не эталон продукта.
- `04_AGENT_HANDOFF/FULL_AUTONOMY_MISSION.md`: полномочия и производственная цель.

Старые ограничения `Gate A ONLY`, `не приступать к Gate B/C`, `кооператив запрещён до новой команды` **отменены последним поручением владельца**. Не используй инструкции прошлых архивов. Прототип мог заметно развиться с тех пор: всегда предпочитай фактически актуальный Roblox-проект для анализа текущей реализации.

**Нельзя без подтверждения:** live-публикация/перезапись действующей игры, разрушительные операции с продакшен-профилями, финансовые расходы и отказ от самой жанровой идеи. Неотработанные балансные и UX детали Claude решает сам.
