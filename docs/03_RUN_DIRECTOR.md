# 03 — RUN STATE / PACING / DIRECTOR

## 1. Конечный автомат

`LOBBY → PREPARE → COUNTDOWN(3s) → ACTIVE → {UPGRADE_MODAL|EVENT_ACTIVE|BOSS_ACTIVE} → {VICTORY|DEFEAT|ABORT} → RESULTS → LOBBY`

При смерти отменить активные вражеские атаки, заморозить результат забега, один раз вычислить награды; UI получает `runId` и итог. Двойная выдача награды по повторному RemoteEvent запрещена. При дисконнекте забег завершается без победных наград; судьба частичной добычи — отдельно определена в doc.07.

## 2. Временная шкала P1

| Фаза | t | Новое событие | Проверка ощущения |
|---|---|---|---|
| Entry | 0–30s | первые 8–12 слабых существ, никаких сложных угроз | «стрелять приятно» |
| Growth A | 30–90s | опыт и 1–2 выбора upgrade | «владею ситуацией» |
| Growth B | 90–150s | плевуны/ускорение; катушка | «начинаю думать» |
| Elite | 150–210s | 1 бронированная элита, выпадение ядра гарантировано | «получил редкую находку» |
| Evolution | 210–300s | гарантировать доступ к первой эволюции при минимальных действиях | «оружие реально изменилось» |
| Swarm | 300–330s | высокая плотность мелких существ | «я машина уничтожения» |
| Hive | 330–380s | три гнезда, бонус за их убийство | «короткая цель внутри хаоса» |
| Breather | 380–420s | снизить давление, дать pickup/upgrade | «передышка» |
| Boss | 420–540s | босс, победа или hard-limit в 9 минут | «финал и результат» |

Не блокировать `UPGRADE_MODAL` в соло: симуляцию ставить на паузу. В будущем коопе — upgrade выбирается из заранее подготовленного списка между фазами, и игра не встаёт на паузу для всей группы без отдельного решения.

## 3. Spawn Director: управляемое давление

Счётчик давления `pressure` 0..1 — функцию фаз и активности игрока. Каждые **0.5с** (design target) система вычисляет оставшийся бюджет активных врагов и допустимые типы. Никакой постоянной масштабируемой физики для всех юнитов.

- `baselineActiveCap = 70` обычных/элитных противников в одиночном P1 на среднем целевом телефоне — **гипотеза, корректируется профилем**, а не обещание.
- `spawnPerSecond`: начало 2–3, середина 4–6, пик 7–10, ограничено доступными слотами; число **посещений** уровня может превышать лимит одновременного количества.
- Визуальная «огромная толпа» достигается прежде всего массовой композиционной группировкой, недорогими смерть-эффектами, музыкальным подъёмом. Не создавать 500 дорогих NPC одновременно.
- `pressure` влияет на долю быстрых/дальних врагов; не подстраивать пул полностью против текущего билда.
- За одну фазу сложных приоритетных врагов не более 20% популяции; иначе орда перестаёт быть ордой.
- Интервал подсчёта урона/FX для цепей ограничен; док.04 и 09.

Постановка: два главных направления на старте → 2–3 направления в середине → короткие предсказуемые пики; на боссе мелкие враги ограничены. Система избегает «мгновенных наказаний»: никаких врагов в упор без предупреждения.

## 4. Выбор улучшений

Ориентир: 1 предложение из 3 каждые 40–60 секунд до заполнения **6 слотов модификаций** (примерно к 5:00–5:30), но не строго по таймеру — опыт от убийств. После 6-го выбора полоса опыта помечается «MAX», новых предложений больше нет; не имитировать бесконечную прокачку. **Страховка RNG:** гарантированное предложение первого модификатора до 60с; 1 шанс получить связанный ключ к эволюции к 180с; при отсутствии ключа к 210с элитная награда позволяет выбрать недостающий; к ~240с открыта гарантированная первая эволюция для игрока, который активно сражался.

В прототипе можно сначала сделать deterministic picks по одной эталонной ветви и вторую доступную ветвь, затем подключить честный weighted pool. Никогда не выдавать три бесполезных/несовместимых предложения.

## 5. Боссы и скрипты

Босс в 7:00. При живом боссе к 8:00 — режим ярости с видимым предупреждением, к 9:00 дефит (не бесконечный баланс-лок). В P1 успешное убийство всегда приводит к экрану результата, не к открытой бесконечной игре.

## 6. Random seed и тестируемость

`runSeed`, `phase`, `eventId`, `selectedUpgrades`, `evolutionId`, `bossResult` логируются в dev. Команды доступные только в Studio: задать seed, ускорить фазу, заспавнить элиту, выдать upgrade, переключить качество VFX, показать spawn debug. В опубликованной сборке dev команды недоступны обычным игрокам.
