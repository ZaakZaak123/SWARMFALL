# Тестовое место SPOREFALL: проверка лагеря и перелётов (DD-053)

Отдельный опыт, **не основная игра**. Нужен, потому что телепорты между серверами в Studio не работают.

## Собрать

```
rojo build test.project.json -o build/SPOREFALL_TEST.rbxlx
```

От обычной сборки отличается одним: у `ReplicatedStorage` атрибут `TestPlace = true`. Внизу экрана тогда видна строка «ТЕСТОВОЕ МЕСТО · ЛАГЕРЬ / СЕРВЕР ОТРЯДА · сервер xxxxxx · игроков N».

## Опубликовать (делает владелец)

1. Открыть `build/SPOREFALL_TEST.rbxlx` в Studio.
2. File → **Publish to Roblox As…** → **Create new experience**. Не выбирать существующую игру SPOREFALL!
3. Game Settings этого нового опыта:
   - Permissions → Private (только свои аккаунты и друзья);
   - Places → Max players = 20;
   - Security → Enable Studio Access to API Services (для профилей и рейтингов).
4. Ассеты (меши, текстуры) принадлежат аккаунту разработчика. Если новый опыт создан под тем же аккаунтом, они загрузятся.

## Проверить (два аккаунта или ты и друг)

| # | Шаг | Ожидание |
|---|---|---|
| 1 | Первый игрок заходит | Строка «ЛАГЕРЬ». Новый профиль сразу улетает в первую охоту; строка «СЕРВЕР ОТРЯДА», номер сервера другой |
| 2 | Конец охоты → «В ЛАГЕРЬ» | Снова «ЛАГЕРЬ», номер сервера как у публичного (может быть другой экземпляр лагеря) |
| 3 | Второй игрок заходит в тот же лагерь (через «Присоединиться» к другу) | Оба видят друг друга, у каждого в руках оружие, над головой имя и титул |
| 4 | Подойти к другому и нажать F | Карточка охотника, «Позвать в отряд» → у второго тост «… зовёт в отряд · Вступить» |
| 5 | Вступить, «В БОЙ» у обоих | Оба улетают вместе, строка «СЕРВЕР ОТРЯДА», игроков 2, бой начинается сам |
| 6 | Итоги → «НА БАЗУ ОТРЯДА» | Оба остаются на базе отряда, можно взять следующую операцию |
| 7 | «В ЛАГЕРЬ» у одного | Он возвращается в лагерь, второй остаётся на базе отряда |
| 8 | Доска отрядов: открыть набор, второй — «Подобрать отряд» | Второй попадает в открытый отряд |
| 9 | Аванпосты → «Посетить» → «♥ Крутой аванпост» | На гнёздах чужие постройки; хозяину тост «… оценил твой аванпост ♥» |

Если что-то не так: F9 (консоль разработчика) → Server. Строки `[SWARMFALL] role …`, `launch squad …`, `session plan …`, `teleport failed …` показывают, где оборвалось.
