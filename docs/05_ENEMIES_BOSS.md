# 05 — ENEMIES, BOSS AND SPAWN BEHAVIOR

## 1. Роли противников (первичный баланс, не тестовые факты)

| ID | Роль | HP | Скорость | Урон | Особенность |
|---|---|---:|---:|---:|---|
| `EN_RUNNER` | Бегун | 24 | 14 studs/s | 7/контакт, CD 1.2с | Стаи, низкая цена спавна, быстрые смерти |
| `EN_STALKER` | Прыгун | 38 | 19 | 9/выпад, CD 3с | Заряжает прыжок 0.65с, красный телеграф |
| `EN_SPITTER` | Плевун | 62 | 8 | 6/тик в кислотном круге, max 3 тика | Дистанция 45–70, видимый круг радиусом 10 перед плевком |
| `EN_BULWARK` | Броненосец | 190 | 7 | 14/удар, CD 2с | Медленный фронтовой блокатор с уязвимым боком |
| `ELITE_BULWARK` | Элитный броненосец | 650 | 8 | 18/удар | 1 фазовый рывок + гарантированное `CORE_STORM` |

Скорости, контактные анимации и HP — конфиги; баланс на тесте в 3 вариантах оружия. Для P1 допускается один переиспользуемый скелет анимации/система без дорогих Humanoid.

## 2. Навигация

Упрощённое групповое steering для обычных врагов, spatial grid, упрощённое обхождение статических препятствий; обновление движения по distance/LOD-бюджету. Враги не должны толкать друг друга физикой, достаточно мягкого separation на логическом уровне. При stuck >2с — обход/мягкое перепозиционирование вне видимости и без урона, метрика `enemy_stuck`. Не телепортировать в упор к игроку.

Структура поведения: `SPAWNING → APPROACH → TELEGRAPH → ATTACK → RECOVER → APPROACH`, и `STAGGER`, `DYING`, `DESPAWN`. У босса свой state graph. Сервер владеет боевым состоянием/HP и решает попадания.

## 3. Приоритет на видимость угроз

- Runner — простой силуэт, эффектная смерть, самая слабая цветовая сигнализация.
- Stalker — заметная подготовка к прыжку и след направления.
- Spitter — кислотный круг на полу **до** урона; без него запрещено запускать атаку.
- Bulwark — большой силуэт, медленное начало атаки, уязвимая область читается сбоку.

В опасный момент не должно одновременно оказаться 8 одинаковых предупреждающих кругов, перекрывающих путь игроку без безопасной зоны. Director регулирует доли и частоту.

## 4. Босс `BOSS_BROODMOTHER` — «Матка разлома»

Силуэт: массивный четырёхлапый инопланетный организм с яркими уязвимыми узлами и двумя центральными отростками. Появляется 7:00 из северных ворот с ~3-секундным аудио/визуальным телеграфом. Первичный HP **4200** для solo P1 (конфиг, под баланс со сформированным билдом); урон по боссу status effect ослаблен по конкретным правилам, не полностью иммунен.

**Фазы:**

- **100–65% HP:** размашистый удар конусом (красный сектор 1.1с до урона); призыв 6–10 бегунов каждые ~14с (ограничен global active cap).
- **65–30%:** удар + «кислотная дорожка» (полосы 2с предупреждения); уязвимые узлы на 5с при промахе тяжелой атаки.
- **30–0%:** рывок на выбранный сектор с 1.4с предупреждения, менее частый призыв. Если время ≥8:00 — усиление давления, но без непрерывных one-shot атак.

Тайм-аут 9:00 → поражение. Все атаки можно избежать базовым движением (рывок облегчает, не является обязательным). Игрок получает окно минимум 3с для DPS после каждого большого приема.

**Победа:** сервер помечает смерть один раз, останавливает спавн, показывает торжество, выдаёт `run_result`. Нельзя получать две награды при одновременных убийствах.

## 5. Режиссёр, health pooling и performance

Пул обычных монстров ограничен конфигом `MaxActiveEnemies` (initial 70). Каждый архетип имеет `spawnCost`: runner=1, stalker=2, spitter=3, bulwark=5, elite=12, boss контролируется отдельно. Общий бюджет — ограничение директора, а не гарантированный каждый кадр зоопарк. Доля особо опасных врагов ≤20% по счётчику. На тестовом телефоне уменьшать cap динамически **между фазами**, если FPS падает; при снижении cap усиливать плотность аудио/FX, но не увеличивать атаки без предупреждения.

## 6. Критерии противников

- 100 последовательных спавнов каждой роли: 0 недоступных/внутристеновых мест.
- Каждая активная атака телеграфируется; нет урона вне её коллайдера.
- После смерти враг никогда не наносит урон и не участвует в поиске цели.
- Статусные эффекты не могут сделать скорость отрицательной, бесконечно заморозить босса или вызвать экспоненциальный proc.
- При KillAll или победе босса освобождаются объекты, коннекты, эффекты, spatial-index записи.
