# 10 — ART, AUDIO, VFX & ASSET LIST

## 1. Визуальная ДНК

Стиль — выразительный, читаемый **stylized 3D Roblox sci-fi**, не реалистичный хоррор, не дешёвый плоский obby. Узнаваемый силуэт персонажа и пушки, яркие читаемые пули, монстры в простых семействах форм. Палитра: тёмный серо-синий фон/инженерия, электрический бирюзовый, оранжевый огонь, фиолетовая плазма, кислотный лайм; цвет подкрепляется формой/звуком.

## 3. Обязательные визуальные уровни

- **Player silhouette:** контрастный, виден в толпе.
- **Enemy role silhouette:** бегун низкий; прыгун длинные задние лапы; плевун крупное кислотное брюхо; броненосец широкий щитовой панцирь.
- **Threat telegraph:** красная напольная фигура и направленный звук **до** атаки; видима при VFX Low.
- **Gun evolution:** не только изменение цвета; две геометрические катушки, другая дульная вспышка, изменённый burst pattern.
- **Horde kill:** краткий recoil врага, death animation/collapse до 0.3–0.5с, затем исчезновение/particle дешёвый; минимальные длительные трупы.

## 4. FX LOD

High: полноценные линии цепей + массовые hit particles; Medium: вдвое меньше вторичных частиц/короче трейлы; Low: только первичные попадания, важные сигналы опасности, краткие chain arcs. **Серверный урон одинаков во всех режимах.** Ограничить одновременные звуковые голоса и эмиттеры; secondary VFX можно cull за пределами камеры.

## 5. Качество, приёмка и запреты

- Начальная стрельба не звучит как пластиковые щелчки; разные типы оружия легко различимы вслепую.
- Игрок видит boss telegraph на максимальной плотности FX.
- Арт-дирекшн утверждается на реальном gameplay кадре со смартфона, не по красивому концепту.
- На P1 нельзя тратить весь срок на детализированные модели, когда стрельба и анимации смерти ещё плохи.
- Не подменять полноценный импорт mesh обещанием `EditableMesh`-генерации: проверить поддержку API и pipeline, для прототипа допустимы локальные Roblox Parts/primitive meshes, но качество оценивается отдельно.
