# 06 — PLAYER, CAMERA, HIT FEEL

## 1. Контроллер движения

P1: ходьба speed 16 studs/s, рывок на 16 studs за ~0.25с (CD 5с; не телепортация через геометрию), жизни 100 HP, on-death завершение забега. Базовая игра должна быть проходима без идеальных реакций/доджа и без покупки апгрейдов.

Прыжок в P1 выключен во время боя (арена без платформинга). Случайно включённый Roblox default jump на mobile — UX-дефект. Не перезаписывать постоянные пользовательские глобальные control настройки вне текущего персонажа. Позиция/скорость проверяется на сервере с допусками на лаг и knockback.

## 2. Камера и прицеливание

**Гипотеза управления:** фиксированный elevated third-person, pitch ~50°, camera distance ~55 studs; игрок расположен ~55% высоты экрана. Для ПК WASD + мышь наведение в плоскость XZ, LMB shoot, Space dash, Q Overdrive, Esc menu. Для mobile левый стик движение, правый стик направление стрельбы (shoot-on-aim), Dash и Overdrive две крупные кнопки в правой нижней зоне, без конфликтов с Roblox UI. Альтернативный mobile режим `AUTO_AIM_ASSIST`: ограниченное магнитное притяжение к цели в узком конусе без автоматического убийства. Это нужно сравнить на пользователях, не объявлять выигравшим заранее.

Нельзя стрелять по экранному UI, если там карта/карточки. Server validation не принимает произвольные координаты попадания от клиента.

## 3. Получение урона

- Контактный урон имеет пер-враг cooldown и краткое grace-окно после удара (~0.4с) для читаемости.
- Красный край экрана, короткая отдача камеры, локальный damage marker по направлению. Сильное дрожание камеры по умолчанию выключено или регулируемо.
- HP регенерирует только от разрешённых улучшений/лечения, автоматической регенерации P1 нет.
- При HP<30% звук/визуал предупреждает, но не перекрывает поле боя.

## 4. Overdrive P1

Убийства обычных существ +1 условная единица, элита +10; шкала 0–100, событие убийства зачитывается только сервером. При 100 — доступна активация, длительность **7 секунд** (design target), после чего шкала обнуляется; раннее накопление не переносится. `OD_STANDARD`: +25% rate of fire, +1 пробиваемая цель, усиленная локальная VFX/аудио форма, **без** неуязвимости. Boss kills/ферминг внешними exploit-ремоутами не засчитываются. В P1 нет покупки Overdrive, refill через Robux и pay-to-win.

Overdrive не должен скрывать опасные зоны и анимации атак; низкое качество VFX сохраняет механические преимущества, не картинки. UI шкала заметна, но не занимает центральную область.

## 5. Отклик стрельбы

Первая пуля визуально вылетает сразу на клиенте, server решает реальную цель. Hitmarkers «предсказанное» vs «подтверждённое» не смешивать в статистике, UI корректирует ложные. Стрельба должна быть отзывчивой при обычном ping, без визуальных тонн частиц на каждую пулю. Sound layers: выстрел/пробой/металл/смерть мелкого врага/уникальный crit; лимит одновременно играющих звуков.

## 6. Accessibility

Слайдеры VFX: High/Medium/Low; screen shake off; подсказки направления урона, крупные кнопки, цвет + форма для статуса, не только красный/зелёный; text scale для ключевых экранов. Ретикл обязан оставаться видимым при цепных молниях.

## 7. Обязательные тесты

Рывок не проходит за границы/через толстую стену; мобильный палец не запускает стрельбу при выборе апгрейда; потеря управления на pause и при death невозможна; реальный server health совпадает с UI после сетевой коррекции; нет accidental double fire на touch+mouse.
